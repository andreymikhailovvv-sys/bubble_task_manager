# Подтверждение электронной почты в Telegram Mini App

## Исправленный сценарий

В Mini App пользователь открывает **⚙ Настройки → Аккаунт**, даже если у его старого Telegram-аккаунта пока нет логина, пароля и email.

1. Укажите электронную почту, если её ещё нет, либо проверьте уже сохранённый, но неподтверждённый адрес.
2. Нажмите **«Сохранить email и подтвердить»**. Отправляется письмо с шестизначным кодом (15 минут) и ссылкой (24 часа).
3. В открывшемся окне Mini App введите код. Можно повторно запросить письмо.
4. Второй вариант: перейдите по ссылке из письма. После возвращения в Mini App статус обновится локально при `activated`, `focus`, `pageshow` или `visibilitychange`. Есть также кнопка **«Я перешёл по ссылке»** для ручной проверки без повторной отправки.
5. Под почтой появится зелёная отметка **«Почта подтверждена»**. Перезагрузка задач, чатов и приложения не требуется.

## Что исправлено

- Ранее раздел «Аккаунт» и окно ввода кода были доступны только в режиме обычного мобильного браузера (`runtime === 'web'`). В `runtime === 'telegram'` они вообще не отображались.
- Кроме того, `PATCH /api/user/profile` отклонял старые Telegram-only аккаунты без логина, email или Google. Теперь привязанный Telegram-аккаунт с валидной сессией также имеет право добавить неподтверждённый email.
- `GET /api/auth/email/status` обновляет только нужные поля и кредитный баланс. Нет циклических запросов раз в несколько секунд.
- У пользователя, у которого не задан пароль, поле называется «Электронная почта аккаунта», без ложного обещания восстановления пароля.

## Проверка

1. Тестовый старый Telegram-аккаунт без email: настройки → ввод → письмо → код → подтверждённый статус.
2. Старый аккаунт с заполненным, но не подтверждённым email: повторная отправка → код.
3. Подтверждение ссылкой в отдельном почтовом приложении и возвращение в Telegram Mini App, без перезагрузки рабочего пространства.
4. Аккаунт с уже подтверждённой почтой: зелёный статус без нового письма.
5. Обновление адреса у аккаунта с паролем: сервер по-прежнему требует текущий пароль для смены почты.
6. Пробный кредит начисляется не больше одного раза: изменён только существующий UI и допуск Telegram-сессий к профилю, схемы БД и выдача кредитов не меняются.

## Развёртывание

Изменения безопасны для существующих пользователей. Prisma-миграции не нужны; почтовый SMTP остаётся прежним. Выложить веб-клиент и сервер из одного коммита.
