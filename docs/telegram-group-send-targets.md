# Telegram: отправка в группы и супергруппы

Быстрая отправка через иконку под сообщением ИИ/пользователя и
встроенная карточка `prepare_telegram_send` теперь предлагают три
типа адресатов:
- **Личные чаты** с людьми;
- **Группы** Telegram;
- **Супергруппы**, включая приватные супергруппы.

«Избранное» остаётся отдельным первым пунктом.

## Как работает

1. Пользователь нажимает кнопку Telegram под любым сообщением или
   просит ИИ: «Подготовь выжимку и отправь в группу Команда проекта».
2. Список адресатов загружается из уже подключённого личного аккаунта;
   показываются только пользователь, группы и супергруппы из реального
   списка диалогов. Поиск ищет также по названию группы.
3. В быстром окне можно выбрать **максимум три** адресата
   (например, две группы и один контакт). Для каждого получателя
   отображается тип «Личный чат», «Группа», «Супергруппа».
4. В карточке ИИ, если группа однозначно определилась по названию,
   она уже выбрана; если совпадений несколько, потребуется выбрать
   вручную. Отправка всё равно требует явного клика пользователя.
5. Задание проходит через прежнюю зашифрованную очередь. При выполнении
   сервер повторно проверяет, что группа **сейчас существует в списке
   доступных диалогов этого Telegram-аккаунта**, и только затем
   посылает сообщение в MTProto. Telegram также проверяет права
   на отправку в эту группу. Если пользователь вышел из группы или
   отправка запрещена, результат помечается ошибкой.

## Безопасность

- **Каналы для вещания, боты, покинутые/удалённые группы и произвольные
  числовые ID не допускаются**.
- ID типизированы: `group:chat:<id>` и
  `group:supergroup:<id>`. Они не пересекаются с ID личных чатов.
  Сервер не считает формат ID достаточным разрешением на отправку,
  он всегда выполняет реальную проверку доступного диалога владельца.
- Новый owner-only API `/api/telegram-user-client/chat/send-targets`
  возвращает **только имена и типы диалогов**, никаких сообщений.
  Изменение состояния защищено существующей сессией Планировыча
  и same-origin проверкой.
- Прежние API чтения личной истории и анализа
  **по-прежнему исключают группы**, то есть их сообщения ни
  автоматически, ни случайно не передаются в OpenAI.
- Сохраняются лимиты отправки, idempotency / одноразовый audit,
  лимит 1–3 адресата, подтверждение кнопкой и подключение
  индивидуального Telegram через «Интеграции».
- Новых переменных окружения, миграций и действий в Timeweb нет.
- Фоновый мониторинг и автоматические ответы в группах не включены.

## Проверка после Merge

1. Открыть быструю отправку и найти группу. Она должна иметь
   метку «Группа» или «Супергруппа».
2. Отправить тест в группу, где разрешено писать, и проверить доставку.
3. Выбрать группу + личный контакт + «Избранное»: всё должно работать
   с существующими ограничениями частоты (возможна пауза).
4. Написать ИИ «Сделай краткое резюме и отправь в группу Команда проекта»;
   проверить выбранную группу и единственную кнопку подтверждения.
5. Проверить, что каналы Telegram не появились в получателях.
6. Убедиться, что чтение истории в предыдущей панели Telegram
   остаётся доступным **только для личных чатов**.
