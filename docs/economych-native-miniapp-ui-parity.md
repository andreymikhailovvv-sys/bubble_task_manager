# Экономыч Android: визуальный паритет с мини-апп

Эталон для нативного Compose: `client/src/EconomicApp.css` (правила
`.econ-mobile-workspace` и действующие переопределения `.econ-root.econ-light`),
`client/src/EconomicReport.css`, структура `EconomicApp.tsx`.

Нативная реализация **не заменяется WebView**. Переключение разделов, работа с
финансовыми API, редакторы и нижние Android-шиты остаются Kotlin/Compose.

## Общие принципы

- Светлый фон внутри «Экономыча» с очень мягким голубым градиентом
  `#F8FBFF → #F1F5F9` (вместо плоского серого). Общий токен фона остаётся
  `#F7F8FA`, карточки разделов `#FFFFFF`, вложенные счета `#F8F9FB`;
  текст `#202A38`, вторичный `#647181`.
- На обзорной странице четыре карточки статистики имеют минимальную высоту
  136 dp, кремовую заливку `#FFFAF2`, подзаголовок у нижнего края. Две строки
  идут с внутренним расстоянием 11 dp, а от группы до соседних разделов
  добавляется ещё 8 dp. Сами тематические блоки сохраняют белый фон.
- Основной счёт на обзоре мягко акцентируется фоном `#FFF9F2` и рамкой
  `#EFD3B1`. Остальные счета остаются нейтральными.
- Акцент `#DF8B25` только для интерактивных элементов, иконок и выделений.
  Тёмная тема использует прежнюю тёплую палитру с фоном `#12131B`.
- Отступ экрана 13 dp, между блоками 11 dp; основные карточки радиусом 17 dp,
  padding 14 dp, вложенные счёта padding 12 dp. Без двойных тяжёлых контуров.
- Заголовок экрана 22 sp, заголовки блоков 15 sp SemiBold, вспомогательный
  текст 10–11 sp Normal. Суммы выделяются сильнее названий/метаданных.
  Не использовать ExtraBold для обычных названий счетов и операций.
- В навигации компактные чипы, размеры и отступы близкие к мини-апп.
  Светлые бейджи доходов/расходов не должны получать почти чёрную заливку.
- Плашки с кредитами выводят реквизиты аккуратной сеткой 2×N вместо длинной
  стены строк, с сохранением всех сумм, сроков и расчётов.
- Состояния (свёрнутый отчёт, закрытые кредиты), действия редактирования,
  удаления и наполнение остаются прежними. Финансовые расчёты не менять.
- Нативный редактор использует прежнюю стабильную высоту и скролл шита;
  визуальная типографика и плотность полей подстраивается под мини-апп.

При дальнейших UI-правках сверять **обе темы**, длинные названия счетов,
большие суммы, нулевые состояния, календарные и финансовые шиты и
доступность кнопок. Android `versionCode` меняется только по отдельному запросу.
