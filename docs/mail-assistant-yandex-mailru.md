# Почтовый ИИ-ассистент: Яндекс и Mail.ru

Функциональность: подключения нескольких почтовых ящиков через официальный IMAP с TLS (порт 993), наблюдение за **новыми** входящими письмами и доступной папкой «Отправленные», краткая аналитика, предложения задач с подтверждением или явное автоматическое создание.

## Настройка сервера (обязательно)

1. В окружении **основного API-сервера Timeweb** задайте отдельный ключ шифрования:
   \`MAIL_ASSISTANT_ENCRYPTION_KEY=<64-символьный hex-ключ>\`.
   Создать локально: \`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"\`.
   **Нельзя использовать** \`JWT_SECRET\` и нельзя менять ключ после подключения ящиков без миграции данных: существующие пароли перестанут расшифровываться.
2. Убедитесь, что основная переменная \`OPENAI_API_KEY\` установлена: это существующий механизм сервиса для ИИ.
3. Примените Prisma-миграции при очередном деплое. Стандартный \`server:start\` вызывает автоматическую миграцию.
4. Проверьте, что Timeweb разрешает исходящие TLS-соединения на \`imap.yandex.ru:993\` и \`imap.mail.ru:993\` без перехвата сертификата.
5. Не копируйте ключ в клиент или Render; API работает на Timeweb. Не логируйте пароли приложений или письма.

Если ключ отсутствует или имеет неверную длину, управление подключениями явно недоступно, фоновый мониторинг не запустится.

## Для пользователя: Яндекс Почта

1. Разрешите IMAP в настройках почтовых программ Яндекс Почты.
2. Откройте https://id.yandex.ru/security/app-passwords, создайте пароль приложения для «Почта» с именем «Планировыч».
3. В Планировыче откройте **Интеграции → Почтовый ИИ-ассистент → Добавить почту → Яндекс Почта**, укажите полный адрес и созданный пароль приложения.
4. Выберите мониторинг, интервал и способ создания задач. При желании настройте инструкции ИИ.

## Для пользователя: Mail.ru

1. В Mail.ru откройте **Все настройки → Безопасность → Пароли для внешних приложений**.
2. Включите доступ почтовых программ по IMAP и создайте пароль для подключения «Планировыч».
3. В интеграциях выберите **Mail.ru**, введите адрес и пароль приложения. Выберите настройки ИИ.

**Никогда не вводите основной пароль от аккаунта.**

## Новые настройки и проект

Подключённые ящики отображаются сверху отдельными карточками, как чаты Telegram-ассистента. У выбранного ящика четыре раздела: **Ответы на письма**, **Добавление задач**, **Частота сводок**, **Общие параметры**.

В разделе ответов: наблюдение без ответа, предложения ответов с ручной отправкой, автоматические ответы с отдельным согласием. Доступны правила и периодичность. Ответы отправляются через TLS SMTP сервера провайдера (Yandex: smtp.yandex.ru:465, Mail.ru: smtp.mail.ru:465). Проверьте доступность также и этих портов с основного сервера Timeweb. Пароль приложения должен иметь право отправлять письма; если выдали только чтение, отправка не сработает.

В общем ИИ-чате появляется системный проект **Почтовый ассистент** с иконкой @, и по одному чату на адрес почты: **Письма Mail.ru · адрес** либо **Письма Яндекс · адрес**. В этих чатах выводятся сводки, задачи с существующими кнопками подтверждения и предложения ответов. Для важных событий, задач и ответов выводятся системные уведомления и уведомления в личном подключённом Telegram-боте. При выключении мониторинга фоновые действия не запускаются.

В общем разделе можно выбрать модель и дневной лимит расхода AI-кредитов для каждого ящика. Дневной лимит отдельно ограничивает расход общего кошелька. При нехватке кредитов анализ прекращается.

## Ограничения

- **Никакого импорта истории** в этом этапе: сканируются новые письма после подключения.
- Содержимое вложений пока не читается. Простые текстовые MIME-части доступны, сложные вложенные письма могут быть пропущены.
- Предложения ответов отправляются только при явном одобрении. Автоматическая отправка выполняется только при выборе режима **Автоответы**. Настройки ответа должны исключать рекламные, автоматические и сомнительные письма.
- Сообщения SMTP помечаются до сетевого вызова. Если подтверждение провайдера неизвестно (тайм-аут/сбой), повторная автоматическая отправка блокируется, чтобы предотвратить дубликаты.
- Отправленные письма не удаляются и не меняются на сервере. Краткие итоги хранятся в базе; исходный текст письма передаётся OpenAI, но не сохраняется в базе.
- Периодичность «Сразу» означает планировщик с интервалом примерно 15 секунд и зависит от времени ответа IMAP/ИИ и нагрузки сервера, а не гарантированную мгновенную доставку.
- Почтовый OAuth для Яндекса можно добавить позднее, предварительно зарегистрировав OAuth-приложение и поддержав IMAP XOAUTH2. OAuth для входа в Mail.ru не следует считать гарантией права чтения почты.
- Удаление ящика удаляет локальные данные из Планировыча. Пароль приложения необходимо дополнительно отозвать у провайдера, если доступ больше не нужен.
